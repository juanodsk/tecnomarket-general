# Valores editables de Bruno

La colección manual no usa variables, environments ni expresiones con llaves. Cada petición contiene valores literales visibles.

- IDs 100xxx: recursos del Negocio A.
- IDs 200xxx: recursos del Negocio B.
- IDs 900xxx: recursos globales o IDs deliberadamente inexistentes.
- PEGAR_: token o cookie que debes pegar.
- CAMBIAR_: ruta o valor obligatorio que debes sustituir.
- EDITAR_: valor de negocio que debes revisar antes de enviar.

Copia siempre los IDs reales desde data.id de la respuesta que creó el recurso. No existe captura automática.
